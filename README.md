# Amnezia Folder Manager

**Amnezia Folder Manager** — бесплатная утилита для Windows, которая упрощает управление приложениями, при использовании VPN через AmneziaVPN.

Вместо ручного добавления каждого исполняемого файла программа позволяет подключать целые каталоги, автоматически находить EXE и выбирать, какие приложения должны попадать в конфигурацию AmneziaVPN.

## Возможности

- 📁 **Сканирование каталогов** — автоматический поиск EXE во вложенных папках.
- ✅ **Управление приложениями** — включение и исключение отдельных EXE и целых папок с помощью галочек.
- 🔄 **Обновление списка** — обнаружение новых приложений и проверка существующих файлов.
- 💾 **Работа с резервными копиями** — открытие оригинальных backup AmneziaVPN и создание обновлённых файлов для обратного импорта.
- 🧠 **Восстановление настроек** — сохранение истории каталогов, исключений и состояний галочек даже при повторном экспорте конфигурации из AmneziaVPN.
- 🔍 **Поиск** — быстрый поиск приложений и папок по названию.
- 🛡️ **Защита исходных данных** — оригинальная резервная копия не изменяется.
- 🖥️ **Удобный интерфейс** — графическое приложение с тёмной темой для Windows.

## Как это работает

1. Экспортируйте резервную копию из AmneziaVPN.
2. Откройте её в Amnezia Folder Manager.
3. Добавьте каталоги, содержащие нужные приложения.
4. Отметьте EXE, которые не должны использовать VPN.
5. Создайте обновлённую резервную копию.
6. Импортируйте полученный файл обратно в AmneziaVPN.

При последующих экспортах программа может автоматически восстановить ранее управляемые каталоги и сохранённые исключения.

## Требования

- Windows 10/11
- AmneziaVPN
- Windows PowerShell 5.1 для запуска версии `.ps1`

## Особенности

Программа не изменяет файлы приложений, не вмешивается в работу VPN-подключения и не требует ручного редактирования конфигурации AmneziaVPN.

Все пользовательские настройки сохраняются локально в `%APPDATA%\AmneziaFolderManager`.
