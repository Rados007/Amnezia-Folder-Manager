# Amnezia Folder Manager

Утилита для Windows, которая добавляет игры и программы в split tunneling
AmneziaVPN сразу пачкой — без ручного перебора `.exe`.

## Как работает

Сканирует папки игр, показывает найденные `.exe`, дописывает выбранные
в ваш `.backup` AmneziaVPN и сохраняет **новый** `.backup` рядом с собой.
Исходный `.backup` не изменяется.

## Возможности

- Мультипапки, поиск, сортировка по имени / размеру / дате
- Исключения подпапок (Tools, Editor, Redist и т. п.) — в обе стороны
- Автоматическая чистка отсутствующих `.exe` при «Обновить» и «Backup»
- Тёмная тема, адаптация под DPI (Full HD / 2K / 4K)
- Проверка обновлений на GitHub — одной кнопкой
- Всё хранится рядом с `.exe` — портативно

## Использование

1. Сделайте свежий backup в AmneziaVPN
2. Запустите `AmneziaFolderManager.exe`
3. Добавьте папку игры и отметьте нужные `.exe`
4. Нажмите **«Backup»** и выберите исходный `.backup` из шага 1
5. Импортируйте новый `.backup` в AmneziaVPN

## Требования

Windows 7+ / PowerShell 5.1 (встроен)
