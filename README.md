# Amnezia Folder Manager

**Удобный менеджер приложений для AmneziaVPN на Windows.**

Amnezia Folder Manager — бесплатная программа с открытым исходным кодом для управления списком приложений, используемых в настройках раздельного туннелирования (Split Tunneling) AmneziaVPN.

Программа позволяет добавлять целые папки с играми и приложениями, находить исполняемые EXE-файлы, выбирать нужные и формировать резервную копию для импорта в AmneziaVPN.

## ✨ Возможности

- 📁 Добавление папок с играми и программами.
- 🌳 Удобное дерево каталогов с вложенными папками.
- ✅ Выбор отдельных EXE-файлов или целых папок.
- 🔍 Поиск приложений по названию.
- 🔄 Ручное обновление списка EXE.
- 💾 Автоматическое сохранение выбранных папок и приложений.
- 📦 Создание резервной копии `Amnezia-UPDATED.backup`.
- 🔎 Предварительный просмотр изменений перед экспортом.
- 🛡️ Защита существующих записей конфигурации от случайного удаления.
- 🎨 Тёмный интерфейс в стиле Discord.
- 🖥️ Поддержка Windows и сборки в EXE.

## 🚀 Как пользоваться

1. Запустите Amnezia Folder Manager.
2. Добавьте папки, содержащие игры или приложения.
3. Выберите EXE-файлы, которые необходимо включить в конфигурацию.
4. Укажите исходную резервную копию AmneziaVPN.
5. Создайте обновлённый backup.
6. Импортируйте полученный файл `Amnezia-UPDATED.backup` в AmneziaVPN.

**Важно:** программа не изменяет настройки AmneziaVPN напрямую. Все изменения применяются через импорт резервной копии.

## ⚙️ Сохранение настроек

Добавленные папки и выбранные приложения автоматически сохраняются в:

`%APPDATA%\AmneziaFolderManager\folders.json`

Благодаря этому настройки сохраняются после перезапуска и обновления программы.
