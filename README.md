# Amnezia Folder Manager

Утилита для Windows, которая помогает массово добавлять приложения в **исключения split tunneling** AmneziaVPN.

Программа не меняет AmneziaVPN напрямую: берёт ваш `.backup`, дописывает отмеченные `.exe` и сохраняет **новый** backup. Исходный файл не перезаписывается.

**Версия:** 8.9.3  
**Автор:** Rados  
**Платформа:** Windows 10 / 11 · PowerShell 5.1+

---

## Возможности

- Добавление директорий (игры, лаунчеры, программы)
- Дерево всех найденных `.exe` с размерами файлов
- Выбор, какие приложения попадут в backup
- Создание обновлённого `.backup` + текстовый отчёт
- Фильтр по имени файла
- Кэш сканирования — повторный запуск быстрее
- Автопроверка обновлений на GitHub
- Drag & Drop папок в окно
- Горячие клавиши
- Тёмная тема, DPI-aware интерфейс
- Сохранение размера и позиции окна

---

## Как пользоваться

1. Сделайте свежий **backup** в AmneziaVPN.
2. Запустите **Amnezia Folder Manager**.
3. Нажмите **«Добавить директорию»** и укажите папку (Steam, игра, лаунчер и т.п.).
4. В дереве отметьте `.exe`, которые должны работать **без VPN**.
5. Нажмите **«Создать Backup»** и выберите исходный `.backup` из шага 1.
6. Импортируйте созданный файл `Amnezia-UPDATED-….backup` в AmneziaVPN.

> Снятые галочки **не удаляют** приложения из уже существующего backup — утилита только **добавляет** новые.

## Горячие клавиши

| Клавиша | Действие |
|--------|----------|
| `Ctrl+F` | Фокус в фильтр |
| `F5` | Обновить всю базу (пересканировать папки) |
| `Delete` | Удалить выбранную папку из списка |

## Контекстное меню (ПКМ по дереву)

- Открыть папку / папку с файлом  
- Пересканировать  
- **Удалить папку**  
- Обновить всю базу  
- Отметить всё / Снять все отметки  
- Развернуть всё / Свернуть всё

## Файлы данных

Рядом со скриптом (или в `%APPDATA%\AmneziaFolderManager`, если нет прав на запись):

| Файл | Назначение |
|------|------------|
| `folders.json` | Список папок и отмеченные exe |
| `folders.json.bak` | Резервная копия настроек |
| `Amnezia-UPDATED-*.backup` | Новый backup для импорта |
| `Amnezia-UPDATED-*.txt` | Отчёт о добавленных приложениях |

Лог: `%TEMP%\amnezia-fm.log` (двойной клик по журналу в программе).

---

## Важно

- Исходный `.backup` **никогда** не перезаписывается.
- Утилита не требует прав администратора (если хватает доступа к выбранным папкам).
- При повреждении `folders.json` настройки восстанавливаются из `.bak`.
